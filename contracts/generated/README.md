# Generated Contracts

CI-generated aggregate and audience-filtered contracts belong here, including the complete internal OpenAPI bundle and the allowlisted external bundle. Do not edit generated files manually.

Audience filtering reduces accidental exposure but never replaces server-side authorization. See [ADR-0016](../../docs/08-架构决策/ADR-0016-Taro内部移动端与外部多端技术栈.md).
