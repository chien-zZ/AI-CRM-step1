# Business Configuration Contracts

Source contracts for business dictionary and typed-parameter definitions, immutable releases, effective-dated activation, historical resolution, version-aware results, events, and stable public errors.

Contracts do not contain secrets, deployment settings, arbitrary executable expressions, SQL, permissions, workflow routes, or unconfirmed CRM dictionary items and parameter values.

See [ADR-0013](../../docs/08-架构决策/ADR-0013-版本化表单与业务配置中心.md).
