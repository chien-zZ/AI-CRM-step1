# 第一阶段通知范围

## 已确认范围

- 自研业务中立通知中心控制面。
- PostgreSQL 持久化通知、实际收件人、站内投递和用户状态。
- PC Web 通过 TanStack Query 轮询通知列表和未读数。
- 受限 Mustache 纯文本模板、变量 JSON Schema 和不可变版本。
- 最小用户偏好、幂等、RabbitMQ Worker、重试、死信、审计和对账能力。
- 外部渠道使用稳定 `ChannelAdapter` 边界，但不实现任何具体渠道。

## 明确不在第一阶段

- 企微应用消息、微信订阅消息、短信、邮件、JPush、APNs、FCM 或厂商手机推送。
- WebSocket、SSE 或其他长连接实时通知。
- 营销群发、公告、合规送达、呼叫中心和复杂通知旅程编排。
- 任何尚未确认的 CRM 提醒、预警、模板、收件角色和触发条件。

## 进入后续范围前置条件

- 对应客户端或渠道已正式批准。
- 明确服务商、地址来源、账号关联、费用、配额、模板审核、退订/偏好和合规要求。
- 提供独立测试环境、测试账号、凭据注入方式和失败演练条件。
- 定义渠道交付语义、幂等、重试、回执、死信、人工重放和监控告警。

不得把“已经预留 ChannelAdapter”理解为已经实现或承诺任何外部渠道。
