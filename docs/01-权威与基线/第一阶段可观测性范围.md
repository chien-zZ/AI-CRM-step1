# 第一阶段可观测性范围

- 状态：已批准
- 日期：2026-07-23
- 适用阶段：公共技术底座与业务无关 walking skeleton
- 架构依据：ADR-0010、ADR-0020、ADR-0021、ADR-0022

## 范围

第一阶段采用：

- Pino JSON 结构化日志与 Docker 日志轮转。
- OpenTelemetry/W3C Trace Context 标准和跨 HTTP、Outbox、RabbitMQ、Worker 的关联传播。
- 托管 Sentry 错误聚合、Release 标记和受控采样性能 Trace。
- 腾讯云云监控的 CVM/基础组件监控，以及位于两台服务器故障域之外的可用性探测。
- 存活、就绪和受控深度诊断约定。
- 告警级别、Owner、升级路径、抑制和 Runbook 要求。

## 自研、开源与托管边界

- 项目自研薄 `packages/observability`，统一字段、脱敏、上下文、初始化和测试。
- Pino、OpenTelemetry API/语义约定和 W3C Trace Context 使用成熟开源能力。
- Sentry 和腾讯云云监控使用托管服务，不在两台服务器自建观测后端。
- 审计日志继续由 `audit` 平台模块自研并耐久保存，不进入 Sentry。

## 第一阶段不交付

- OpenTelemetry Collector、Prometheus、Grafana、Loki、ELK/Elastic Stack、Alertmanager 或自托管 Sentry。
- 从应用日志推断业务事实、审计事实、销售指标或 SLA。
- 未验证的微信小程序 Sentry SDK 集成。
- 带有 Token、Cookie、Secret、个人敏感信息、客户正文或完整供应商载荷的日志和错误事件。
- 没有 Owner、窗口、抑制和 Runbook 的生产告警。

## 启用门禁

- Sentry 生产启用前确认账号地域、数据处理与跨境要求、保留、删除、访问权限和退出方案。
- 每个应用验证数据清洗、Release/Environment、采样、Source Map 和 SDK 失败行为。
- 预发布验证受控异常、外部可用性失败、告警触发、恢复通知和人工处置。
- 日志轮转、磁盘上限和组件健康信号在两台服务器拓扑下验证。

## 待确认

- Sentry 与腾讯云账号、区域、套餐和告警接收渠道。
- 日志/Sentry 保留、采样率、阈值和静默窗口。
- 微信小程序错误报告 Adapter。
- 正式 SLI/SLO 和容量基线。

## 非目标

- 本基线不承诺任何 SLA、RPO 或 RTO 数值。
- 本基线不批准上传真实客户数据进行调试。
