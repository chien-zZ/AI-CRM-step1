# 第一阶段部署范围

- 状态：已批准
- 日期：2026-07-23
- 适用阶段：公共技术底座与业务无关 walking skeleton
- 架构依据：ADR-0003、ADR-0010、ADR-0011、ADR-0021

## 已知事实

- 第一阶段生产部署采用两台腾讯云 Ubuntu CVM 和自托管 Docker Compose。
- PostgreSQL、Redis、RabbitMQ、Keycloak、Flowable、Nginx 和 ClamAV 不使用生产托管版本。
- 当前没有已批准的并发、容量、SLA、RPO、RTO、机器规格和备份保留期。

## 第一阶段必须建立

- 本地、CI/测试、预发布和生产的显式环境边界。
- 两台服务器各自独立的版本化 Compose Project，以及应用和状态组件的服务放置说明。
- API 双副本、Worker、Nginx、PostgreSQL、Redis、RabbitMQ、Keycloak、Flowable 和 ClamAV 的健康、资源、网络和停止行为。
- 不可变应用镜像、固定第三方镜像、逐台发布、冒烟验证和应用回滚。
- PostgreSQL 全量/基础备份、WAL 归档、异地 COS 保存和从空服务器恢复演练。
- 管理端口私网隔离、最小安全组、Secret 引用、日志轮转和基础故障告警。

## 明确接受的限制

- 两台服务器不是状态组件的完整高可用或自动仲裁集群。
- API 双副本不能消除 Nginx、PostgreSQL、Redis、RabbitMQ、Keycloak 或 Flowable 的单点故障。
- 故障恢复允许包含人工处置，但对外承诺前必须测得真实恢复时间和数据恢复点。

## 第一阶段不交付

- Kubernetes、Docker Swarm、自动跨可用区故障转移和自动扩缩容。
- 未经批准的三节点数据库、Redis Sentinel 或 RabbitMQ Quorum 集群。
- 腾讯云托管 PostgreSQL、Redis 或 RabbitMQ。
- 没有固定版本、健康检查、备份责任或恢复说明的生产容器。
- 任何硬编码 Secret、生产 `.env`、默认密码或公开管理端口。

## 待确认

- 服务器规格、服务放置、入口切换、组件版本和网络拓扑。
- RPO、RTO、备份保留、恢复演练频率和 Owner。
- Secret 管理与可观测产品选型。

## 非目标

- 本基线不定义 CRM 业务模块、上线规模或服务等级协议。
- 本基线不把历史材料中其他已废弃技术选择重新设为正式结论。
