## 2. 状态机与完成规则

工作包使用以下状态：

```text
BACKLOG -> READY -> IMPLEMENTING -> SELF_REVIEW -> INDEPENDENT_REVIEW
  -> FIXING -> RE_REVIEW -> G2_ACCEPTED -> MERGED
```

任何阶段均可进入 `BLOCKED`。`EVIDENCE_BLOCKED` 表示授权范围内的仓库代码和发布门已经合并，但必须由受保护环境产生的外部证据尚未闭合；它不等同于仍在实现，也不等同于验收通过。只有专项测试、完整 `pnpm check` 和独立 Review 均通过，且所有可执行 P0/P1/P2/P3 finding 清零、未决架构或契约问题清零，才可进入 `G2_ACCEPTED`。Review 结论必须写入任务 handoff，不能只写 `LGTM`。
