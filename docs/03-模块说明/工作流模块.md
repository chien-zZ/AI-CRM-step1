# 工作流模块

- 模块位置：`packages/platform-modules/workflow`
- 类型：业务中立平台模块
- 状态：边界已确认，接口与实现待契约评审
- 开源组件：Flowable
- 架构依据：ADR-0009

## 职责

- 隔离 Flowable 定义、版本、实例和人工任务 API。
- 提供启动、查询和受控人工任务动作的稳定接口。
- 管理 BPMN 资产部署、版本和兼容边界。
- 发布传输无关的流程与任务生命周期事件。
- 对跨 Flowable 与业务事实源的部分失败提供对账入口。

## 非职责

- 不拥有订单、客户或其他领域对象状态。
- 不直接更新领域数据库。
- 不充当统一任务列表、通知中心、SLA 引擎或后台 Job 引擎。
- 不拥有业务表单内容，不在流程变量中复制完整业务对象。
- 不允许领域模块读取 Flowable 表或使用 Flowable SDK。

## 依赖方向

- Flowable 只存在于本模块适配器和部署边界。
- 通过组织、授权、审计、事件和表单的公开契约协作。
- 流程实例引用不可变表单发布版本或经过批准的必要快照；具体提交数据仍由领域模块所有。
- 领域模块和 Task Center 只能消费 Workflow Facade 或正式事件。

## 失败模式

- Flowable 不可用或调用超时。
- 重复启动、重复完成或并发认领。
- 流程完成与业务动作发生部分失败。
- BPMN 版本、变量 Schema 或主体引用不兼容。
- 流程事件丢失、重复或乱序。

所有失败必须有稳定错误、幂等、指标、追踪和对账路径；不能把未知状态当作审批通过。

## 待确认

- 公共 HTTP、事件和错误契约。
- Flowable 版本、部署方式和认证方式。
- BPMN 发布、回滚和实例迁移流程。
- 第一阶段业务中立 walking skeleton 的验收用例。
