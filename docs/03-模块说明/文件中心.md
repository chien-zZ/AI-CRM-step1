# 文件中心

- 模块位置：`packages/platform-modules/file-center`
- 异步运行入口：`apps/worker`
- 类型：业务中立平台模块
- 状态：边界已确认，接口、字段和实现待契约评审
- 架构依据：ADR-0007、ADR-0010、ADR-0011、ADR-0012

## 自研与外部能力边界

- 文件中心控制面：项目自研，管理元数据、会话、版本、业务关联、授权和生命周期。
- 生产二进制存储：使用腾讯云 COS 托管服务，经 `StorageAdapter` 接入，不自建对象存储。
- 本地开发存储：项目自研文件系统适配器，仅用于开发与测试。
- 恶意文件扫描：使用开源 ClamAV，经扫描适配器接入，不自研病毒识别引擎。

## 职责

- 创建、完成和过期上传会话。
- 管理不可变文件版本、可信元数据、分类和处理状态。
- 管理文件与传输中立业务资源引用的关联。
- 在授权后签发短时上传或下载凭证。
- 编排 MIME/大小校验、ClamAV 扫描、隔离、清理和对账。
- 发布文件生命周期事件并记录安全审计。

## 非职责

- 不拥有合同、凭证、客户或其他业务对象及其附件规则。
- 不把 PostgreSQL 当二进制存储，也不把 COS 当元数据事实源。
- 不向业务模块暴露 Bucket、Object Key、签名 URL、永久 URL、COS SDK 或 ClamAV 类型。
- 不提供通用网盘、在线编辑、OCR、电子签章、媒体转码或全文内容搜索。
- 不因文件已经上传就自动允许访问或建立正式业务关联。

## 数据所有权

文件中心拥有以下业务中立事实，具体字段等待契约评审：

- 文件及其不可变内容版本。
- 上传会话和分片上传协调状态。
- 可信大小、探测类型、校验信息和存储适配器引用。
- 校验、扫描、隔离、可用、删除及对账状态。
- 业务资源引用关联、分类、保留和审计引用。

业务模块仅持有稳定 `FileReference`，文件中心仅持有稳定 `ResourceReference`。双方不直接访问对方数据库。

## 公开能力方向

契约确认后，可通过 HTTP 与 `platform-sdk` 提供：

- 申请上传会话并获取短时上传凭证。
- 幂等完成上传、查询校验和扫描状态。
- 建立、替换或解除文件与业务资源的关联。
- 在逐次授权后获取短时下载引用。
- 查询文件版本、处理状态和允许展示的元数据。
- 提交删除、恢复、重扫或对账请求。

公开返回稳定项目标识和状态，不返回存储厂商内部定位信息。

## 核心不变量

- 客户端不能选择或覆盖服务端 Object Key。
- 一个已完成二进制对象不可原地覆盖，替换必须产生新版本。
- 校验和扫描完成前，文件不能作为可下载正式附件。
- 下载必须基于当前主体和当前资源权限重新判断。
- 数据库、COS、RabbitMQ 和 ClamAV 间的部分失败必须可重试和对账。
- 解除业务关联不等于立即物理删除，物理删除服从保留策略。

## 失败模式

- 上传已完成但客户端未调用完成接口。
- 数据库记录存在但 COS 对象缺失，或临时对象存在但会话已过期。
- ClamAV 不可用、超时、特征库过期或文件无法扫描。
- 授权通过后签名失败，或签名发出后权限被撤销。
- 删除状态已提交但 COS 删除失败。

所有失败必须保持明确状态。不得把“上传到 COS”直接显示为“文件可用”，也不得因扫描或签名故障降级为公开访问。

## 待确认

- `FileReference`、上传会话、文件版本、资源关联和错误码契约。
- 大小、类型、分片、签名、临时文件和扫描限制。
- 分类、保留、归档、删除、法务冻结和高敏代理下载规则。
- COS 部署配置和 ClamAV 容量、更新、隔离与告警基线。
