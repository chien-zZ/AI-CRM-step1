# 统一任务中心

- 模块位置：`packages/platform-modules/task-center`
- 类型：业务中立平台模块
- 状态：边界已确认，接口与实现待契约评审
- 架构依据：ADR-0009

## 职责

- 汇总 Workflow 和未来业务系统产生的待处理工作。
- 维护可查询、可筛选和可排序的任务投影。
- 保存来源引用、受理范围、投影状态、截止时间和安全深链。
- 将认领、完成等命令路由回任务事实源。
- 通过事件重放和对账修复投影漂移。

## 非职责

- 不成为审批状态或业务状态事实源。
- 不自行完成 Flowable Task 或修改领域对象。
- 不负责通知投递、SLA 计时或后台 Job 重试。
- 不以通知已读、外部渠道送达或模板渲染状态替代任务认领、完成和来源状态。
- 不直接读取 Flowable 或领域模块数据库。

## 投影不变量

- 来源类型与来源任务标识必须稳定且唯一。
- 重复和乱序事件不能产生重复任务或状态回退。
- 来源已完成但投影滞后时，以来源事实为准并通过对账修复。
- 候选任务与已认领任务的可见性必须经过授权。
- 深链只能指向经过授权的应用路由，不能携带敏感数据。

## 失败模式

- 来源事件延迟、重复、乱序或丢失。
- 投影与事实源状态不一致。
- 来源系统不可用，无法执行任务动作。
- Assignment 失效或任务受理人变化。

任务中心必须明确显示不可处理或同步中的状态，不能把路由失败伪装成任务完成。

## 待确认

- 多 Assignment 下的任务合并和上下文切换方式。
- 查询、分页、排序和保留策略。
- 来源对账频率与修复操作权限。
