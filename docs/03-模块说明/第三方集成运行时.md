# 第三方集成运行时

- 模块位置：`packages/platform-modules/integration-runtime`
- 运行入口：`apps/api`、`apps/worker`
- 类型：业务中立平台模块
- 状态：边界已确认，公开契约、存储和实现待评审
- 架构依据：ADR-0003、ADR-0010、ADR-0020、ADR-0022

## 自研与开源边界

- 项目自研轻量 Port 辅助、调用编排、错误分类、Webhook 安全框架和项目观测接入。
- HTTP、TLS、密码学、JSON 校验和 OpenTelemetry 使用 Node 标准能力或成熟开源库；第一阶段错误与采样 Trace 接入 Sentry，主机/可用性接入腾讯云云监控。
- RabbitMQ、Redis、PostgreSQL 分别承担异步传输、短期协调和耐久技术事实。
- 供应商官方 SDK/REST 只能在具体 Adapter 中使用，不进入运行时公共契约。

## 职责

- 提供 Deadline、重试预算、退避、限流、熔断、请求关联和脱敏原语。
- 提供 Webhook 原始报文、验签、时间戳/Nonce、防重放和耐久接收接口。
- 提供供应商中立的技术错误、调用尝试、接收状态、健康和对账辅助。
- 提供 Fake/Stub Adapter、故障注入和契约测试工具。
- 将通用指标、日志和 Trace 接入项目可观测体系。

## 非职责

- 不拥有订单、支付、人员、通知、文件、AI 输出或其他业务事实。
- 不提供任意外部 URL 调用、通用脚本、字段映射语言或业务流程编排。
- 不保存完整供应商业务对象，也不从技术调用记录推断业务成功。
- 不替代拥有模块的授权、状态校验、幂等、对账和人工处置规则。
- 不直接向领域模块暴露供应商 SDK、HTTP Client、Secret 或原始异常。
- 不拥有 AI 用途、Prompt/模型策略、Token 预算、Proposal 或人工确认；这些属于 `ai-gateway` 和拥有模块。

## 公开能力方向

- 构造受策略约束的出站调用执行器。
- 注册 Provider Adapter 的错误映射、验签器和健康探测。
- 耐久登记并异步分发已验证的 Webhook 接收。
- 查询脱敏后的技术调用、积压、失败和对账状态。
- 在测试中模拟超时、429、5xx、重复、乱序和凭据轮换。

具体接口先在 `contracts/integrations/` 评审。业务模块仍使用自己定义的能力 Port，不调用通用 `execute(url, payload)`。

## 数据所有权

- 供应商无关的调用尝试和 Webhook 技术接收状态。
- 重放防护、请求指纹、外部事件引用和安全诊断引用。
- 具体字段、保留期限和是否需要持久化必须由首个真实集成验证。

Redis 数据不是耐久事实；供应商完整载荷默认不保存，确需保存时单独进行加密、权限和保留评审。

## 失败模式

- DNS、连接、TLS、超时、429、5xx、供应商业务拒绝和未知错误码。
- Webhook 签名错误、时间戳过期、Nonce/事件重复、未知版本或解析失败。
- RabbitMQ、Redis、PostgreSQL 或 Secret 解析不可用。
- Adapter 成功但业务命令失败，或业务已取消但异步调用仍到达。

所有失败保持稳定分类并默认失败关闭；可重试性由操作契约决定，不能从 HTTP 状态机械推断。
