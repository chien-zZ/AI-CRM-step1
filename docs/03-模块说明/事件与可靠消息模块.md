# 事件与可靠消息模块

- 模块位置：`packages/platform-modules/eventing-outbox`
- 运行入口：`apps/worker`
- 类型：业务中立平台模块
- 状态：边界已确认，接口、表结构和实现待契约评审
- 架构依据：ADR-0003、ADR-0010、ADR-0020

## 自研与开源边界

- RabbitMQ：使用开源产品，负责消息传输、路由、确认、受控重试、死信和一次性延迟触发。
- Redis：使用开源产品，负责缓存和短期执行协调；不保存消息或业务唯一事实。
- Outbox/Inbox：项目自研，负责连接本地数据库事务、项目事件契约与消费者幂等语义。
- 项目自研 RabbitMQ/Redis 适配器和运行策略，不修改两个开源项目的源码。

## 职责

- 校验传输中立事件信封和版本化载荷。
- 在生产者本地事务中可靠登记 Outbox 消息。
- 将已提交 Outbox 消息发布到 RabbitMQ，并处理 Publisher Confirm、重试和积压。
- 为消费者提供耐久 Inbox 去重和本地事务包装。
- 声明并验证 RabbitMQ 拓扑、消费策略和死信路由。
- 为私有 Worker Job 提供入队、延迟唤醒、取消语义和运行状态接口。
- 提供积压、失败、重放、对账和死信处置的运维能力。

## 非职责

- 不拥有业务状态、审批状态、任务中心投影或提醒规则。
- 不保证端到端恰好一次，也不提供跨数据库和 RabbitMQ 的分布式事务。
- 不把 Redis 锁、缓存或延迟消息当成任务应否执行的判断依据。
- 不允许领域模块直接使用 RabbitMQ/Redis 客户端、拓扑名称或 Outbox/Inbox 表。
- 不把 Worker Job 载荷发布为稳定领域事件。
- 不拥有供应商协议、验签、字段映射或集成业务结果；这些由拥有模块、`integration-runtime` 和具体 Adapter 按 ADR-0020 分工。

## 公开能力方向

在契约评审后，模块可以通过 `platform-sdk` 或公开入口提供：

- 在现有本地事务中追加版本化事件或可靠异步请求。
- 使用确定性幂等键提交、查询或取消允许取消的后台任务。
- 注册带 Inbox 保护的事件消费者和 Job Handler。
- 查询发布、消费、重试和死信状态。
- 由授权运维人员执行重放、跳过、隔离和对账。

接口必须使用项目契约模型，不暴露 RabbitMQ Channel、Delivery、Exchange、Redis Client 或厂商异常类型。

## 数据与事实源

- Outbox 是“本地事务已承诺发送”的耐久记录，RabbitMQ 是传输层。
- Inbox 是指定消费者已经完成本地副作用的耐久记录，Redis 去重键只是可丢失的加速层。
- Job 状态用于执行追踪，不替代发起任务的领域事实。
- Outbox/Inbox 表位于应用数据库的模块自有 Schema，由 `eventing-outbox` 所有；其他模块只通过正式事务参与接口写入，不能直接访问表。具体表结构等待契约和迁移评审。

## 不变量

- 未提交的本地事务绝不能产生可见消息。
- 消费者本地副作用提交前不得确认 RabbitMQ 消息。
- 同一消息对同一消费者重复投递时，最多产生一次已提交的本地副作用。
- 所有延迟和周期触发在执行前重新检查权威状态。
- 生产者和消费者都不能依赖全局消息顺序。
- 所有人工重放和死信处置必须授权、审计并保留操作原因。

## 失败模式

- 数据库提交成功但 RabbitMQ 暂时不可用：Outbox 保留，发布器恢复后补发。
- RabbitMQ 已接收但发布状态未更新：可能重复发布，由 Inbox 和业务幂等吸收。
- 消费者处理后未确认：RabbitMQ 重新投递，Inbox 返回已有结果或安全跳过。
- Redis 不可用：停止依赖分布式锁的高风险任务；不丢失 Outbox/Inbox 耐久事实。
- 消息不可解析、版本不支持或重试耗尽：隔离至死信并告警，不无限循环。
- 延迟消息已到达但业务已取消：Handler 读取权威状态后无副作用完成。

第三方异步调用默认经本模块的 Outbox/RabbitMQ/Inbox 可靠链路到达 Worker；`integration-runtime` 不另建消息传输或第二套重试队列。传输重投、调用重试和业务补偿必须分别记录，不能混为同一种“重试”。

## 待确认

- 事件信封、Outbox/Inbox 和 Job 状态的具体字段与约束。
- RabbitMQ 拓扑命名、版本、延迟实现、重试与死信运行策略。
- Redis 键空间、TTL、锁算法和故障降级规范。
- 运维重放 API、权限、审计和控制台范围。
